PostgreSQL pgJDBC adapter for Scriptella.

General information

Driver class:scriptella.driver.postgresql.Driver
JDBC driver class:org.postgresql.Driver
URL:jdbc:postgresql://host:5432/database
Runtime dependencies: pgJDBC (postgresql-VERSION.jar), supplied through the connection classpath.
