SQLite adapter for file-backed databases using the sqlite alias. Canonical jdbc:sqlite: URLs are also detected by the default auto driver.

Supply Xerial org.xerial:sqlite-jdbc:3.53.4.0 externally through the connection classpath or application runtime classpath; it is not bundled.

<connection driver="sqlite" url="jdbc:sqlite:/absolute/path/source.db"
            classpath="lib/sqlite-jdbc-3.53.4.0.jar"/>

The JDBC class is org.sqlite.JDBC. Common JDBC properties and transaction behavior apply; see the JDBC package overview.

Verified scope: file-backed schema creation, reads/writes, persistence, signed 64-bit integers, common numeric values, Unicode/text, NULL versus empty text, commit, rollback, and SQLite to PostgreSQL migration.

SQLite NUMERIC/REAL can lose high-precision decimal digits. Xerial may return Double values, and PostgreSQL NUMERIC binding may round further. Arbitrary numeric migration is not lossless. Explicit conversion is required for exact decimals and cannot restore precision already lost in source REAL storage.

See SQLite setup and migration example.
